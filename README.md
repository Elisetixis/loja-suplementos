# Loja de Suplementos

Projeto desenvolvido para gerenciamento e exibição de produtos de uma loja de suplementos.

##  Como rodar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/Elisetixis/loja-suplementos.git
```

### 2. Acesse a pasta

```bash
cd loja-suplementos
```

### 3. Importe o banco de dados

Abra o MySQL e execute:

```sql
SOURCE backend/banco.sql;
```

### 4. Instale as dependências

```bash
npm install
```

### 5. Inicie o servidor

```bash
node server.js




Tecnologias utilizadas

* Node.js
* Express
* MySQL
* HTML, CSS, JavaScript
